# Third-party assets

Piece sets and board textures come from the Lichess source repository
(https://github.com/lichess-org/lila, `public/piece/*` and `public/images/board`);
licences as listed in its COPYING.md. Piece SVGs were rasterised to 160 px PNG and board
textures resized to 640 px JPEG; no other changes were made.

Lichess piece sets under CC BY-NC-SA (California, Maestro, Cardinal, Fresca, Gioco, Tatiana,
Staunty, Caliente, Anarcandy, …) and "free for personal use" sets (Alpha, Companion, Leipzig, …)
are intentionally NOT included: their terms are incompatible with distributing this project under the GPL.
The plain colour boards (Brown, Blue, Green, Purple, IC) are just colour values in styles.plist.

## App icon
Resources/Icon*.png are resized copies of the picture supplied by the project owner (a black knight on an orange square,
file name "Chess ndd45.svg"). The knight artwork matches Colin M.L. Burnett's piece set from Wikimedia Commons
(multi-licensed: GPLv2+ / CC BY-SA 3.0 / BSD); please check the licence of your original file before publishing the app.

## Wood background
Resources/wood_background.jpg is a JPEG copy of the wood picture supplied by the project owner; its licence/source is not
recorded here, please make sure you have the right to distribute it.
